# 現在の保有艦娘一覧

2026年6月時点の保有艦娘。レベル降順。
任務必要度は [missions/required_ships.md](../missions/required_ships.md) に基づく。

- **◎**: 繰り返し任務（M/Q/Y）で必要 → 最優先保有
- **○**: 単発任務で艦名指定あり → 保有推奨
- **△**: 艦名指定任務なしだが汎用性・Tierが高い → 残留推奨
- **▽**: 艦名指定任務なし、用途次第 → 保留
- **✗**: 艦名指定任務なし、低Tier → **解雇候補**
