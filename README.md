# kancolle

艦隊これくしょん（艦これ）の艦娘運用を最適化するためのリポジトリ。

## 目的

保有する艦娘を可能な限り **100隻以内（目標80隻程度）** に絞り込み、効率的に運用する。

## 解雇基準

以下の条件を **いずれも満たさない** 艦娘は解雇候補とする:

- その艦娘が **限定の任務（クエスト）** を持っている
- その艦娘が **特定海域の攻略に必須**（ルート固定・特効など）

逆に言えば、任務にも海域攻略にも関与しない艦娘は解雇対象。

## 運用方針

- 艦種バランスを考慮しつつ、汎用性の高い艦娘を優先して残す
- イベント海域で特効が見込まれる艦娘は保護対象とする
- データはこのリポジトリで管理し、判断の根拠を記録として残す
